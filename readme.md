# 洛克图鉴 APP

洛克图鉴是一款面向《洛克王国：世界》玩家的图鉴应用，提供精灵、技能、蛋组等资料查询，以及异色收集记录和攻略辅助功能。

## 功能

- 精灵图鉴
- 精灵异色混刷查询
  - 自定义混刷查询
  - 赛季异色混刷快速查询
- 蛋组图鉴
- 技能图鉴
- 异色记录
  - 支持按身份卡区分记录
  - 支持多设备云端同步
  - 记录已获取的赛季异色
  - 支持手动和自动记录
  - 提供数据统计
- 远行商人
- 地图广场
  - 采矿路线
- PVP 阵容
- 配种模拟器

## 安装说明

目前提供 iOS IPA 版本，需要使用 [AltStore](https://altstore.io/) 完成自签名后安装。

## 异色记录自动化配置

自动化异色记录需要配合
[roco-helper（洛克助手）](https://github.com/h3110w0r1d-y/rocom-helper) 使用。
请先完成 `roco-helper` 的配置并启动服务。

1. 打开洛克图鉴的系统设置，在“网络云端设置”中点击 `roco-helper`。

   ![打开 roco-helper 设置](./public/roco-helper/01.png)

2. 配置服务地址：
   - 可以手动输入洛克王国世界助手的服务端 IP 地址。
   - 如果不清楚 IP 地址，可以扫描局域网设备。应用会自动扫描当前网关下的 `4939` 端口，并查找已正确部署 `users` 接口的设备。若设备处于不同网段，请手动设置 IP 地址。
   - 如果 `roco-helper` 使用 HTTPS，请选择 HTTPS 协议；使用自签名证书时，还需要开启“跳过证书校验”，否则可能无法扫描或访问服务。

   ![配置服务地址](./public/roco-helper/02.png)

3. 点击“新增记录”，再点击页面右下角的齿轮按钮，配置需要记录的 UID 角色。

   ![配置 UID 角色](./public/roco-helper/03.png)

   多账号场景下，请选择正确的角色，否则可能无法正确获取数据。连接成功后，角色和设置按钮旁会显示绿色圆点；如果开启了双牌通知，齿轮右上角会显示红色圆点。
